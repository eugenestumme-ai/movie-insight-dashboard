# Movie Insight Dashboard

A modular Python data analytics application designed to process, filter, and visualize cinematic datasets using modern data science libraries.

## 🚀 Project Overview
This project provides an end-to-end data analysis pipeline for exploring movie datasets. It automates data cleaning, computes key statistical summaries, and generates publication-grade visual analytics to uncover trends in film ratings, runtimes, and financial performance.

## 🔑 Key Features & Technical Capabilities
* **Data Filtering & Manipulation:** Built custom filtering functions using `pandas` to isolate specific genres, release year ranges, or rating thresholds.
* **Statistical Summaries:** Automated descriptive statistics generation to analyze central tendencies and distributions across box office revenue and viewer scores.
* **Visual Analytics:** Leveraged `Seaborn` and `Matplotlib` to render clean correlation matrices, distribution curves, and trend charts.
* **Structured Codebase:** Organized as a clean Python script (`movie_dashboard.py`) with complete documentation and modular functions.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Seaborn, Matplotlib
